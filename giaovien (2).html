Đề của tôi

Xem kết quả đề soạn ở máy khác
Cài đặt Firebase lần đầu (chỉ làm một lần)

Vào Firebase → Realtime Database → tab Rules, xóa hết nội dung cũ, dán đoạn dưới đây rồi bấm Publish.

{
  "rules": {
    "exams":   { ".read": true, ".write": true },
    "results": { ".read": true, ".write": true },
    "lop12a1": { ".read": true, ".write": true }
  }
}

Không gửi link của trang này cho học sinh. Học sinh chỉ cần link hoặc mã QR của từng đề.
